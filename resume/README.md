# Resume

## How it works

`resume-base.json` is the single source of truth for resume content. `profile/` is the source of truth for who you are, what you want, and why. Skills read from both — never edit the HTML or PDF directly.

Five Claude Code skills are available (run them from inside this `resume/` directory). Full detail on each — arguments, output structure, and worked examples — lives in [`.claude/skills/README.md`](.claude/skills/README.md); the summary below is just enough to pick the right one.

| Skill | Command | Use it to... |
|---|---|---|
| `adapt-resume` | `/adapt-resume <job-posting-url>` | Tailor the resume and generate a cover letter for one job posting |
| `render-resume` | `/render-resume <name>` | Render the untailored base resume to PDF |
| `prep-recruiter-call` | `/prep-recruiter-call <application-folder>` | Prep for a recruiter screening call |
| `prep-hiring-manager` | `/prep-hiring-manager <application-folder> <name-or-linkedin>` | Prep for a hiring-manager or panel interview |
| `review-applications` | `/review-applications` | Synthesise patterns across all past applications — what's working, what's failing |

## Directory map

| Path | Purpose |
|---|---|
| `resume-base.json` | Untailored resume content — the single source of truth |
| [`profile/`](profile/README.md) | Who you are: narrative, values, motivations, STAR stories, logistics |
| [`applications/`](applications/README.md) | One folder per job application, generated by the skills above |
| [`.claude/skills/`](.claude/skills/README.md) | The skill definitions themselves |

Each linked folder has its own README with full detail — this file stays a map, not a duplicate.

Job-description classification and the cross-application job-market dashboard used to live here under `analysis/` — that's moved to the separate `analytics-engineers-job-descriptions` repo.

## Updating the base resume

Edit `resume-base.json` directly. Key fields:

| Field | Purpose |
|---|---|
| `summary` | The professional summary paragraph |
| `experience[].bullets` | Bullet points per role — order matters for `/render-resume` |
| `skills.technical` | Ordered list of skill categories |
| `skills.certifications` | Certifications list |
| `pillHighlights` | Tags shown in the interactive HTML version only |

After editing, run `/render-resume base` to regenerate the base PDF.

## Prerequisites

- **Chrome** must be installed at `/Applications/Google Chrome.app` for PDF generation. If not found, the skill will output the HTML and ask you to print it manually via File → Print → Save as PDF.
- Skills require Claude Code to be running inside this `resume/` directory.
